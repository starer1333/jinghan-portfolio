## 发布与维护 / Publishing

网站为静态 HTML、CSS 和 JavaScript，使用本项目的 GitHub Pages 发布。
发布源为 `main` 分支的仓库根目录 `/`；无需 npm 安装或构建命令。
项目路径为 `/jinghan-portfolio/`，页面与资源采用相对链接。
原 jinghanwang260724-png 账户中的个人网站仓库保持不变。
更新后可在仓库 [Actions](https://github.com/starer1333/jinghan-portfolio/actions) 查看部署状态。

本地预览：在仓库目录运行 `python -m http.server 8000`，再访问 `http://localhost:8000/`。

写信表单会打开访客的邮件应用，由访客确认发送；网站不会直接发送或在服务器保存留言。
